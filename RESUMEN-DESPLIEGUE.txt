┌──────────────────────────────────────────────────────────────────────┐
│ PASO 2: Subir Código a DonWeb                                       │
└──────────────────────────────────────────────────────────────────────┘

OPCIÓN A - Git (más fácil):
  1. Crear repo en GitHub
  2. Subir código:
     git add .
     git commit -m "Proyecto completo"
     git push origin main
  
  3. En DonWeb (por SSH):
     ssh usuario@tu-dominio.donweb.com
     git clone https://github.com/tu-usuario/turnero-peluqueria.git
     cd turnero-peluqueria

OPCIÓN B - FileZilla (alternativa):
  1. Conectar por SFTP a tu VPS
  2. Arrastrar carpeta turnero-peluqueria completa
  3. Asegurarte de incluir el archivo .env


┌──────────────────────────────────────────────────────────────────────┐
│ PASO 3: Desplegar en DonWeb                                         │
└──────────────────────────────────────────────────────────────────────┘

En el VPS (por SSH):

  cd turnero-peluqueria
  
  # Dar permisos
  chmod +x deploy-donweb.sh
  
  # Desplegar TODO
  ./deploy-donweb.sh
  
  # O manualmente:
  docker-compose build --no-cache
  docker-compose up -d
  
  # Ver progreso
  docker-compose logs -f

╔══════════════════════════════════════════════════════════════════════╗
║  🆘 PROBLEMAS COMUNES                                                ║
╚══════════════════════════════════════════════════════════════════════╝

Frontend no muestra datos:
  → Verificar API_URL en .env
  → cat .env | grep API_URL
  → Debe tener el dominio público, no localhost

Backend no inicia:
  → docker-compose logs backend
  → Verificar variables de BD

Error 502:
  → Backend no está corriendo
  → docker-compose restart backend

No puedo conectar por SSH:
  → Verificar usuario y dominio/IP
  → ssh -v usuario@dominio (para ver errores)
